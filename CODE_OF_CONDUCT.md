# Community Code of Conduct

## Our Pledge

We are committed to providing a welcoming, constructive, and harassment-free environment for everyone participating in the **Student & College Management System (SCMS)** project, regardless of background, identity, or level of experience.

## Expected Standards

Participants in this project are expected to:
- **Demonstrate Respect**: Communicate courteously, value diverse perspectives, and handle technical disagreements constructively.
- **Provide Actionable Feedback**: Focus critiques on code, architecture, and documentation rather than individuals.
- **Collaborate Responsibly**: Respect the project's educational focus, acknowledge academic sources, and uphold academic integrity.
- **Help Others Learn**: Support peers and contributors who are learning relational databases, backend engineering, or web development.

## Unacceptable Behavior

The following behaviors are strictly prohibited:
- Harassment, derogatory comments, or personal attacks.
- Trolling, insulting, or discriminatory speech.
- Publishing private information of others without explicit consent.
- Unwelcome sexual attention or advances.
- Plagiarism or misattribution of project materials.

## Scope & Enforcement

This Code of Conduct applies within all project spaces, including GitHub issues, pull request discussions, and communications related to this repository.

Project maintainers reserve the right to remove comments or contributions that violate these principles. Concerns can be directed to the repository maintainer.
